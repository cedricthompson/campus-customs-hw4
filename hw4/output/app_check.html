Step 2 · Test 1

AI chat inventory and price accuracy

Pass

Goal: the assistant retrieves real inventory and price from the database and doesn't invent anything.

Procedure

  1. Chose a real product with varied stock: Basic Hoodie Big Yale (basic-hoodie-big-yale) and read its record from the database first.
  2. Opened its product page on the live site, opened Handsome Dan, and typed the question below.
  3. Compared every number in the reply against the database.

How this report was produced

Method and authenticity

  • Every screenshot was captured by browser automation from the running application during this test run; none are mock-ups. They are browser-viewport captures, downscaled by the capture tool; click any image to enlarge it. Each image loads from app_check_images/ next to this file, so keep the folder with the report.
  • The database screenshot shows raw output of sqlite3 data/campus_customs.db queries run at test time, displayed in the browser so it could be captured. The temporary file was deleted afterward.
  • Database values in the tables above were read directly with SQL, not copied from the website.
  • Tests ran as a guest so no customer's saved chat appears in the screenshots.
